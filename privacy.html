Claude Tasks privacy policy

Last updated: 2026-10-05

Who runs it

David Seymour runs Claude Tasks for his own use. It is not offered to the public.

What data it uses

With the account owner's permission, Claude Tasks reads and changes the Google Tasks in that account: task lists, task titles, notes, due dates and completion status. It uses the Google permission https://www.googleapis.com/auth/tasks.

How the data is used

The scripts list tasks, create tasks and mark tasks complete when the account owner runs them. When the owner asks the Claude AI assistant to process tasks, the task text is sent to Anthropic as part of that conversation.

Where the data is stored

The Google sign-in token is stored only on the account owner's computer. Claude Tasks has no server and no database. Task data is not sold, and is not shared with anyone else.

How to remove access

Remove Claude Tasks at myaccount.google.com/permissions. This stops all access at once.
